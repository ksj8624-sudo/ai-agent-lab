# README Documentation Request

## 1. 작업 목표

대상 프로젝트의 실제 구현 코드를 분석하여
현재 구현된 기능과 구조를 기반으로 README를 작성한다.

README는 새로운 기능을 추측하지 않으며,
실제 구현된 코드만 기준으로 작성한다.

---

## 2. 분석 대상 프로젝트

프로젝트 경로를 입력한다.

예)

- `/Users/.../private-agent-server`

---

## 3. 참고 문서

필요한 경우 다음 문서를 참고한다.

- 프로젝트 README
- Architecture 문서
- API 명세
- Roadmap
- Design 문서

참고 문서는 실제 구현보다 우선하지 않는다.

실제 코드를 우선한다.

---

## 6. 작성 원칙

- 실제 구현된 기능만 작성한다.
- 구현 예정 기능은 Roadmap에만 작성한다.
- 구현되지 않은 기능을 Completed에 포함하지 않는다.
- 추측하지 않는다.
- 코드 기준으로 작성한다.
- 프로젝트 역할을 명확히 설명한다.
- 다른 프로젝트의 역할과 혼동하지 않는다.
- 불필요한 마케팅 문구는 사용하지 않는다.
